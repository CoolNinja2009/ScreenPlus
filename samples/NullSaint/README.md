# NULL//SAINT

Interactive glitch-cyberpunk web wallpaper for Screen+ / Lively (or any browser: open `index.html` through a local server, press **P** for the control deck).

- Procedural megacity, glyph rain, holo ads, a wireframe artifact
- **The Saint**: a scanline face, giant eye or particle swarm that tracks the cursor, blinks and talks
- **Kei**: an optional, original drawn cyber girl (or drop your own PNG into `girls/`)
- WebGL signal damage: datamosh, pixel sort, RGB split, tearing, VHS, CRT, bloom, ASCII vision, colour modes, mirrors
- 12 glitch events, haunted error popups, phantom cursors that replay your past moves, idle rot, audio reaction, optional synth sound
- 144 settings (`LivelyProperties.json` is generated from `js/config.js`)

Browser keys: `1`–`0`, `-`, `=` events · Space burst · S speak · W worm · B reboot · H HUD · P deck.
